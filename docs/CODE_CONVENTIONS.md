# 코드 컨벤션

사람이든 AI 에이전트든 코드를 쓸 때 **같은 형식**으로 쓰기 위한 규칙입니다. 협업 규칙(브랜치·커밋·PR·리뷰)은 [CONVENTIONS.md](CONVENTIONS.md)를 봅니다.

- 이 문서와 기존 코드가 다르면 **이 문서를 따릅니다**. 기존 코드를 고칠 범위가 아니면 PR 본문의 "남은 작업"에 적습니다.
- 규칙이 맞지 않는 경우가 생기면 코드에서 예외를 만들지 말고 이 문서를 고치는 PR을 엽니다.

## 날짜와 시각

### 기준 시간대는 한국 시간(Asia/Seoul)

- 거래일, 기준일(`as_of`), "오늘"은 모두 **KST 날짜**입니다.
- `date.today()`와 타임존 없는 `datetime.now()`는 쓰지 않습니다. 실행하는 컴퓨터의 시간대를 따르기 때문입니다.
  - GitHub Actions 러너와 대부분의 서버는 UTC라서, 한국 시간 오전 9시 전에 돌면 날짜가 하루 전으로 잡힙니다.
- 오늘 날짜는 KST로 구합니다.

```python
from datetime import datetime
from zoneinfo import ZoneInfo

KST = ZoneInfo("Asia/Seoul")

def today_kst() -> date:
    return datetime.now(KST).date()
```

`backend/agents/trend_report/config.py`에 같은 함수가 있습니다. 새로 만들기 전에 공용 위치로 옮겨 함께 씁니다.

### 저장하고 주고받는 형식

| 종류 | 형식 | Python | DB | API(OpenAPI) |
| --- | --- | --- | --- | --- |
| 날짜 | `YYYY-MM-DD` | `date` | `date` | `format: date` |
| 시각 | ISO 8601 + 오프셋 | 타임존 있는 `datetime` | `timestamptz` | `format: date-time` |
| 연월 | `YYYY-MM` | `str` | `text` 또는 월초 `date` | `string` |
| 분기 | 사업연도 + 분기 정수 | `int`, `int` | `fiscal_year`, `quarter` | 두 필드 |

- 시각을 만들 때는 `datetime.now(KST)`나 `datetime.now(timezone.utc)`처럼 항상 타임존을 붙입니다.
- `str(date)`가 아니라 `.isoformat()`과 `date.fromisoformat()`으로 바꿉니다.

### 외부 API 형식은 수집기 경계에서만 변환

pykrx·ECOS·DART는 `20261116`, `2026.06.30 현재` 같은 자기 형식을 씁니다.

- 이 형식은 **수집기 함수 안에서만** 다루고, 밖으로 내보내는 값은 위 표의 형식으로 바꿉니다.
- 파싱에 실패하면 그 행만 건너뛰고 경고를 남깁니다. 한 행 때문에 배치 전체가 멈추면 안 됩니다.

### 화면 표시

- 화면용 형식(`11월 16일`, `오전 9:00`)은 프런트엔드에서만 만들고, `Intl.DateTimeFormat("ko-KR", { timeZone: "Asia/Seoul" })`을 씁니다.
- API는 표시용 문자열이 아니라 위 표의 원본 형식을 내려줍니다.

## 종목 식별자

| 식별자 | 형식 | 비고 |
| --- | --- | --- |
| 종목코드 `ticker` | `^[0-9A-Z]{6}$` 문자열 | `005930`. 숫자로 바꾸면 앞자리 0이 사라지므로 **절대 `int`로 다루지 않습니다**. 최근 상장 종목은 영문이 섞일 수 있습니다. |
| 우선주 | 종목코드 끝자리가 `0`이 아님 | 재무제표는 보통주(끝자리 `0`) 것을 씁니다. |

| 지표 ID `indicator_id` | `UPPER_SNAKE` | `USD_KRW`, `KTB_3Y_KR` |

- 사용자가 입력한 종목코드는 `strip()` 후 형식을 확인하고, 맞지 않으면 바로 오류를 냅니다.
- CSV·엑셀에서 읽을 때는 `dtype=str`로 읽습니다.

## 숫자와 단위

단위는 **필드 이름이나 주석에 반드시 드러나야** 합니다. 이름만 보고 단위를 알 수 없는 새 필드는 만들지 않습니다.

| 종류 | 규칙 | 예 |
| --- | --- | --- |
| 금액 | 원 단위 정수. DB `bigint` | `revenue = 79_140_000_000_000` |
| 퍼센트 | 이름 끝 `_pct`, 값은 퍼센트 수치 | `operating_margin_pct = 12.5` |
| 확률·비중 | `0~1` 소수. 이름에 `prob`, `share`, `weight` | `prob_up = 0.62` |
| 수익률(계산 중) | 소수 `0.05` = 5% | 로그 수익률도 소수 |
| 비율(배수) | 그대로의 배수 | `per = 12.3`, `pbr = 1.1` |
| 기간 | 단위를 이름에 | `horizon_days = 30`, `timeout_seconds = 20` |

- 억·조 단위 변환과 `%` 표시는 화면에서만 합니다.
- 내부 계산은 소수로 하고, 저장하거나 API로 내보낼 때만 `_pct`로 바꿉니다.
- `NaN`과 `inf`는 저장하지 않습니다. `None`(JSON `null`)으로 바꿉니다. Postgres JSON은 `NaN`을 받지 못합니다.
- 금액을 `float`로 더하지 않습니다. 원 단위 정수로 계산합니다.

## 빈 값(null) 처리

리뷰에서 가장 많이 나온 문제입니다. 원칙은 하나입니다. **모르는 값은 모르는 값으로 둡니다.**

1. **빈 값과 0을 구분합니다.** 값이 없으면 `None`/`null`이고, `0`이나 `""`로 채우지 않습니다.
2. **외부 응답이 비면 "전부 삭제"로 해석하지 않습니다.**
   - 원래 데이터가 있어야 할 응답(상장 종목 목록 등)이 비면 실패로 멈춥니다.
   - 선택적인 데이터가 비면 "이번에는 변경 없음"으로 넘어갑니다.
   - 삭제·상장폐지처럼 되돌리기 어려운 처리에는 건수 상한을 두고, 넘으면 멈춥니다.
3. **일부가 빈 집계는 결과를 `null`로 둡니다.** 4개 분기 합계에 한 분기가 비면, 3개 분기 합계가 아니라 `null`입니다. SQL `sum()`과 pandas `sum()`은 빈 값을 건너뛰므로 개수를 함께 확인합니다.
4. **키는 있는데 값이 `null`일 수 있습니다.** `raw.get("name", "")`은 키가 없을 때만 기본값을 씁니다. `(raw.get("name") or "").strip()`으로 씁니다.
5. **있어야 할 컬럼은 항상 만들어 둡니다.** pivot 뒤에는 `reindex(columns=[...])`로 기대 컬럼을 맞추고, 빈 컬럼은 경고를 남깁니다.

## 이름 짓기

| 대상 | 규칙 |
| --- | --- |
| Python 변수·함수·모듈 | `snake_case` |
| Python 클래스 | `PascalCase` |
| 상수 | `UPPER_SNAKE` |
| TS 변수·함수 | `camelCase`, 컴포넌트·타입은 `PascalCase` |
| API JSON 필드 | `snake_case`. 프런트엔드도 받은 이름을 바꾸지 않고 그대로 씁니다. |
| DB 테이블·컬럼 | `snake_case` |
| 환경변수 | `UPPER_SNAKE`, 영역 접두어 (`DEBATE_LLM_MODEL`, `TREND_REPORT_TOP_K`) |
| 날짜 필드 | 날짜는 `_date` 또는 `as_of`, 시각은 `_at` (`trade_date`, `created_at`) |

- 영어 약어를 새로 만들지 않습니다. 화면에 보이는 이름은 한국어로, 코드 이름은 영어로 씁니다.
- 찬성·반대·판정 에이전트는 코드에서 `bull`·`bear`·`judge`, 화면에서 `찬성`·`반대`·`판정`으로 씁니다.

## 설정과 환경변수

### 어디에 둘지

모든 값을 `.env`로 옮기는 것이 하드코딩 해결이 아닙니다. 값의 성격에 맞는 위치에 둡니다.

| 위치 | 맞는 값 | 예 |
| --- | --- | --- |
| **환경변수 (비밀)** | 인증키, 비밀번호, 접속 주소 | `DART_API_KEY`, `SUPABASE_DB_URL` |
| **환경변수 (일반 설정)** | 배포 환경마다 다르거나 운영 중 조정하는 값 | 모델 이름, 타임아웃, 요청 간격, 수집 상한 |
| **코드 상수 / Enum** | 바뀌지 않는 규칙, 외부 API의 고정 값, 수학 상수 | DART 보고서 코드 `11011`, `PAGE_SIZE` 최대값, 거래일 수 `252` |

### 필수와 선택을 나눕니다

- **필수 설정**은 없으면 기능이 동작하지 않는 값입니다. **프로그램 시작 시점**에 확인하고, 없으면 무엇이 빠졌는지 이름을 적어 바로 종료합니다. 요청을 처리하다가 실패하게 두지 않습니다.
- **선택 설정**은 코드에 기본값을 두고, 없어도 동작합니다.
- 필수 값의 기본값을 빈 문자열로 두지 않습니다. 빈 문자열은 "설정됨"으로 보여서 확인을 통과합니다.

```python
REQUIRED = ["SUPABASE_DB_URL", "DART_API_KEY"]

def check_required_env() -> None:
    missing = [name for name in REQUIRED if not os.getenv(name)]
    if missing:
        raise SystemExit(f"필수 환경변수가 없습니다: {', '.join(missing)} (.env 확인)")
```

`backend/agents/trend_report/config.py`의 `require_env()`가 같은 역할을 합니다.

### 새 환경변수를 추가할 때

1. 해당 영역의 `.env.example`에 한 줄 설명과 함께 추가합니다. 비밀값은 값을 비워 둡니다.
2. 필수인지 선택인지, 선택이면 기본값을 주석에 적습니다.
3. GitHub Actions에서 쓰는 값이면 [ENVIRONMENT.md](ENVIRONMENT.md)의 표에도 추가합니다.

### 프런트엔드 환경변수는 공개 값입니다

- `VITE_`로 시작하는 값은 빌드 결과물에 그대로 들어가서 누구나 볼 수 있습니다.
- API 키나 비밀값을 `VITE_` 변수에 넣지 않습니다.

## 에러와 로그

- `print` 대신 `logging.getLogger(__name__)`을 씁니다.
- 비밀값을 로그·예외 메시지·PR 본문에 남기지 않습니다.
  - URL에 키가 들어가는 API(DART 등)는 예외 메시지에서 키를 가리고, `httpx` 로거는 `WARNING`으로 올립니다.
  - 공개 저장소의 GitHub Actions 로그는 누구나 볼 수 있습니다.
- 예외를 잡을 때는 무엇이 실패했는지(종목, 날짜, 단계)를 메시지에 넣습니다.
- 예외를 삼키고 빈 결과를 돌려주지 않습니다. 실패했다는 사실이 호출자에게 전달되어야 합니다.

## 배치 적재

종목·날짜 여러 개를 처리하는 적재기는 다음을 지킵니다.

1. **한 건의 실패를 격리합니다.** 종목이나 연도 단위로 예외를 잡아 기록하고, 다음 건을 계속 처리합니다.
2. **실패도 기록합니다.** 가능하면 `status = 'error'`와 이유를 행으로 남겨서 "결과 없음"과 "실패"를 구분합니다.
3. **실패가 많으면 실패로 끝냅니다.** 실패 비율이 기준을 넘으면 0이 아닌 종료 코드로 끝내서 스케줄러가 알 수 있게 합니다.
4. **다시 실행해도 안전하게 만듭니다.** upsert를 쓰고, 한 배치 안의 중복 키는 보내기 전에 제거합니다.
5. **완료 표시는 마지막에 씁니다.** 처리 완료를 뜻하는 값(새 상장주식수 등)은 관련 작업이 모두 성공한 뒤에 저장합니다.
