# 브랜드 에셋

## 캐릭터

<img src="app-icon-192.png" alt="개미비서단 캐릭터" width="120" height="120" />

리서치 리포트를 들고 가는 개미입니다. 서비스가 하는 일을 그대로 그림으로 옮겼습니다.

- **개미** — 서비스가 돕는 대상인 개인 투자자
- **들고 있는 리포트** — 증권사 애널리스트 리포트. 서비스는 이 리포트를 모아 근거로 씁니다
- **리포트 속 파랑·금색·빨강 막대** — 하락·중립·상승. Bull/Bear 토론이 만들어내는 세 갈래 시나리오와 몬테카를로 결과를 뜻합니다. 국내 증시 관례대로 상승이 빨강, 하락이 파랑입니다

원본 캐릭터 일러스트에서 들고 있던 잎사귀를 리포트로 교체해 만들었습니다.

## 심볼

<img src="symbol.svg" alt="개미비서단 심볼" width="64" height="64" />

캐릭터는 파비콘처럼 작은 크기에서 형태가 뭉개집니다. 32~64px 이하에서는 위에서 내려다본 개미를 단순화한 이 심볼을 씁니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `character.png` | 캐릭터 원본 (1024px, 배경 투명). 문서·발표자료 삽입용 |
| `app-icon-512.png` | 앱 아이콘 원본 (밝은 타일 배경) |
| `app-icon-192.png` | README·문서 삽입용 |
| `symbol.svg` | 작은 크기용 단순 심볼 (파비콘, 탭 아이콘) |
| `logo-lockup.svg` | 심볼 + 이름 가로 조합 (텍스트는 시스템 폰트로 렌더링) |

## 색

| 이름 | 값 | 용도 |
| --- | --- | --- |
| Ink | `#16211C` | 심볼 배경, 본문 텍스트 |
| Paper | `#EFEAD9` | 밝은 배경, 어두운 면 위 텍스트 |
| Tile | `#F2EFE6` | 앱 아이콘 배경 |
| Gold | `#D6A94F` | 강조, 중립 시나리오 |
| Up Red | `#C1443F` | 상승 |
| Down Blue | `#4E86C4` | 하락 |

## 사용 규칙

- 캐릭터 주변에 최소 여백(캐릭터 높이의 1/10)을 둡니다.
- 캐릭터의 비율과 색을 임의로 바꾸지 않습니다. 리포트 속 막대 색은 상승·하락 의미를 담고 있으므로 특히 바꾸지 않습니다.
- 어두운 배경에 올릴 때는 `character.png`(배경 투명) 대신 타일 배경이 있는 `app-icon-*.png`를 씁니다. 개미가 짙은 갈색이라 어두운 배경에서는 형태가 묻힙니다.
- 64px 이하에서는 캐릭터 대신 `symbol.svg`를 씁니다.

## 다시 만들기

캐릭터는 원본 일러스트(래스터)에서 잎사귀 영역을 색으로 분리해 제거하고, 그 자리에 리포트를 그려 넣은 뒤 개미 픽셀을 다시 위에 얹는 방식으로 합성했습니다. 리포트 모양을 바꾸려면 같은 방식으로 다시 합성해야 합니다. `symbol.svg`는 순수 벡터라 직접 수정할 수 있습니다.
