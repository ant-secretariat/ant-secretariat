# 브랜드 에셋

## 심볼

<img src="app-icon-192.png" alt="개미비서단 심볼" width="96" height="96" />

위에서 내려다본 개미가 세 개의 막대 위에 서 있는 형태입니다.

- **개미** — 서비스가 돕는 대상인 개인 투자자
- **금색 더듬이** — 정보를 먼저 더듬어 찾아주는 비서 역할
- **파랑·금색·빨강 막대** — 하락·중립·상승. 토론(Bull/Bear)이 만들어내는 세 갈래 시나리오와 몬테카를로 결과를 뜻합니다. 국내 증시 관례대로 상승이 빨강, 하락이 파랑입니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `symbol.svg` | 기본 심볼. 크기 제한 없이 사용 |
| `logo-lockup.svg` | 심볼 + 이름 가로 조합. 발표자료 표지용 (텍스트는 시스템 폰트로 렌더링) |
| `app-icon-512.png` | 파비콘·앱 아이콘 원본 |
| `app-icon-192.png` | README, 문서 삽입용 |

## 색

| 이름 | 값 | 용도 |
| --- | --- | --- |
| Ink | `#16211C` | 심볼 배경, 본문 텍스트 |
| Paper | `#EFEAD9` | 개미 본체, 어두운 배경 위 텍스트 |
| Gold | `#D6A94F` | 강조, 더듬이, 중립 시나리오 |
| Up Red | `#C1443F` | 상승 |
| Down Blue | `#4E86C4` | 하락 |
| Line | `#3C4741` | 구분선, 베이스라인 |

## 사용 규칙

- 심볼 주변에 최소 여백(심볼 높이의 1/8)을 둡니다.
- 심볼의 비율과 색을 임의로 바꾸지 않습니다. 단색이 필요하면 Paper 또는 Ink 한 색으로만 출력합니다.
- 밝은 배경에도 어두운 배경에도 그대로 올립니다. 타일 자체가 배경을 갖고 있습니다.
- 아이콘을 텍스트 옆에 쓸 때는 `logo-lockup.svg`를 쓰고, 심볼과 글자를 따로 배치해 간격을 임의로 조정하지 않습니다.

## 다시 만들기

PNG는 `symbol.svg`와 같은 좌표계를 Pillow로 그려 생성했습니다. 심볼을 고치면 SVG와 PNG를 함께 업데이트해야 합니다.
