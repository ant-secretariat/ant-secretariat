# 0002. 민감도 회귀 요인은 KOSPI·원달러 환율·국고채 3년으로 하고, 국고채 10년은 단순회귀와 상관만 둔다

- 상태: 채택
- 결정일: 2026-11
- 결정자: 수경
- 의견을 준 사람: 유민
- 출처: 카톡 대화(유민→수경 질문 1차 3·4번, 2차 1·2번), `sensitivities` 테이블

## 배경

온톨로지 엣지에 종목·섹터의 매크로 민감도를 쓰려면, 어떤 요인으로 회귀를 돌리고 어떤 기준일(as_of) 값을 쓸지 정해야 했습니다. 국고채 10년을 요인에 추가할지, 월별 지표(CPI, 유가)는 어떻게 다룰지도 정해야 했습니다.

## 선택지

- **일별 요인만 다중회귀** — KOSPI, 원달러 환율, 국고채 3년
- **국고채 10년을 다중회귀에 추가**
- **월별 지표를 일별 회귀에 억지로 맞춤** — 월별 값을 일별로 채움

## 결정

- **다중회귀 요인**은 `KOSPI`, `USD_KRW`(원달러 환율), `KTB_3Y_KR`(국고채 3년) 세 개입니다.
- **국고채 10년** `KTB_10Y_KR`은 단순회귀(`simple`)와 `corr_daily`만 산출하고, 다중회귀에는 넣지 않습니다.
  - 국고채 3년과 상관이 약 0.9라, 같이 넣으면 계수가 불안정해지기 때문입니다.
- **월별 지표**(`CPI_KR`, `BRENT` 등)는 일별 회귀로 구하지 않습니다. 시세를 10년치로 늘려 **월별 상관**을 따로 산출합니다.
- **기준일**은 가장 최근 as_of를 씁니다. 현재 2026-11-06이고, 2026-10-21과 10-26 값도 남아 있습니다.
- 현재 **99종목**이 적재돼 있습니다. 삼성에피스홀딩스는 거래일 250일이 모자라 빠졌습니다.

## 영향

- 유가처럼 일별 요인이 없는 매크로 엣지에는 일별 민감도 값이 없습니다. 이런 엣지는 월별 상관을 씁니다.
- 거래일 250일 미만인 신규 상장 종목은 민감도가 없습니다. 사용하는 쪽에서 빈 값으로 처리해야 합니다.
