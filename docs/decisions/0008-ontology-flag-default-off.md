# 0008. 관계 사전 기능 플래그는 기본 꺼짐, 켬/끔 평가로 기본값을 정한다

- 상태: 채택
- 결정일: 2026-11-17
- 결정자: 태은
- 출처: 멀티에이전트 설계 최종 확정(10/14) 5.3, 토론 기획서 v3.0 평가 체계(PR #20)

## 배경

관계 사전 기능 플래그의 기본값이 문서마다 달랐습니다.

- 멀티에이전트 설계 최종 확정: 기본 꺼짐, 켬/끔 블라인드 비교로 효과 확인
- PRD v1.1~v1.5, Design Doc: 시연 설정은 켜짐

관계 근거가 답변 품질을 실제로 높이는지는 아직 측정하지 않았습니다.

## 선택지

- **기본 켜짐** — 관계 근거가 항상 보이지만, 효과를 측정하기 전에 기본 동작이 됨
- **기본 꺼짐, 평가 후 결정** — 효과를 숫자로 확인한 뒤 기본값을 바꿈

## 결정

**기본 꺼짐입니다.** 플래그가 꺼져 있으면 `get_ontology_context`를 호출하지 않습니다.

기본값은 평가 결과로 정합니다(헌법 원칙 V).

- 같은 질문·같은 근거·같은 모델로 켬과 끔의 답변을 만들고, 블라인드 루브릭으로 비교합니다.
- 평가셋은 토론 루브릭셋의 관계 질문 하위셋을 씁니다.
- 관계 종류별 정확도(표본 검수)도 함께 봅니다.
- 켬이 관계 질문에서 우위이고 관계 오류가 없으면 기본값을 켬으로 바꾸는 새 ADR을 씁니다.

관계 사전은 여전히 MVP 기능입니다. **켰을 때 실제로 동작해야 하고**, 시연에서는 켠 상태로 관계 근거를 보여 줄 수 있어야 합니다. 꺼짐은 "기능 제외"가 아니라 "기본값"입니다.

켜져 있을 때도 아래는 그대로입니다.

- `source=placeholder` 엣지와 검수되지 않은 수동 관계는 노출하지 않습니다.
- 조회가 실패하면 토론은 관계 근거 없이 계속하고, 실패를 로그에 남깁니다.

## 영향

- **쉬워지는 것:** 관계 사전의 효과를 근거로 설명할 수 있습니다.
- **감수하는 것:** 평가 전까지 일반 사용 흐름에서는 관계 근거가 보이지 않습니다.
- **바꿔야 하는 문서:** PRD 4.1 관계 사전 완성의 정의, Design Doc 요약·2.1·4.8, 기능 명세서 FN-ONT-01
- **평가 일정:** 4단계(12/7~12/13) 품질 평가에서 켬/끔 비교를 실행하고 결과를 실험 기록에 남깁니다.
