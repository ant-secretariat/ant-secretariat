# NNNN. 결정을 한 문장으로

- 상태: 제안 | 채택 | 대체됨 (→ NNNN) | 폐기
- 결정일: YYYY-MM-DD
- 결정자: 이름
- 의견을 준 사람: 이름 (선택)
- 출처: 카톡 대화 날짜, 관련 PR·이슈 번호

## 배경

어떤 문제나 질문 때문에 결정이 필요했는지 2~5줄로 씁니다.

## 선택지

- **선택지 A** — 한 줄 설명
- **선택지 B** — 한 줄 설명

## 결정

무엇을 선택했는지, 왜 그 선택인지 씁니다.

## 영향

- 이 결정으로 쉬워지는 것
- 이 결정으로 감수하는 것, 나중에 다시 볼 조건
- 바꿔야 하는 코드·데이터·문서

## 참고

- 관련 테이블, 뷰, 함수, 문서 링크
